# Pre-registrations

The three test plans cited in the paper, copied word for word from the commits in the author's
research repository that added them, https://github.com/yelgabo/btest (public since October 8,
2026). Each file gives the commit hash, the commit time (set by the author's machine), and where
available the time GitHub received the push, which GitHub records itself. Notes above each text
describe later corrections; the quoted text is unchanged.
